# Hallazgos de marca — Conejo del Sombrero

Fuente: `CONEJO_brandbook.pdf` aportado por el usuario.

## Identidad

- Nombre: **el conejo del sombrero**, estudio creativo.
- El logotipo es un wordmark de dos pesos; debe conservar sus proporciones y una zona de respeto mínima.
- Lema visual de referencia: “Sacamos ideas del sombrero”.

## Tipografía y motivos

- Tipografía: **Poppins**. Bold/Black para titulares; Regular/Light para texto.
- Motivos: arcos concéntricos finos, retícula de puntos discreta, fondos Berry/Vino y acentos cálidos.
- Aplicación: contraste entre fondos oscuros sofisticados y superficies claras; el dorado debe reservarse para acentos, no para texto extenso.
