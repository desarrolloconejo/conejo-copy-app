# Referencias de hooks en tendencia

Cada referencia representa un hook externo u observado que el equipo desea conservar como **inspiración adaptable**, no como texto para copiar literalmente. Las referencias pertenecen al usuario que las registra, igual que clientes, reglas y fichas.

| Campo | Uso | Obligatorio |
| --- | --- | --- |
| Hook observado | Texto hablado o idea de apertura que se quiere guardar. | Sí |
| Insert-Titulo | Rótulo breve que acompaña el hook. | No |
| Plataforma | Contexto de origen: TikTok, Reels, Shorts u otra. | Sí |
| Territorio | Intención creativa para filtrar: curiosidad, prueba, contradicción, identidad, utilidad, etc. | Sí |
| Fuente | Enlace de referencia, cuando exista. | No |
| Por qué funciona | Observación sobre tensión, escena, prueba o montaje. | Sí |
| Etiquetas | Palabras de búsqueda para el equipo. | No |

La biblioteca incluirá un bloque **Referencias de tendencia** con formulario de carga, búsqueda, filtros de plataforma y territorio, y una acción “Usar como punto de partida”. Esta acción copiará el hook e Insert-Titulo al Canvas, dejando claro que el equipo debe adaptarlos a la verdad del cliente.
