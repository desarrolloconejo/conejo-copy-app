# Auditoría operativa — Conejo Copy Check

## Veredicto

La herramienta ya contiene el criterio necesario para mejorar la calidad de un copy: Canvas, biblioteca, auditor, control de producción, historial y reglas por cliente. Sin embargo, su estructura actual responde primero a un **manual de aprendizaje** y solo después a una **mesa de trabajo diaria**. Para una redactora con varias entregas, el primer gesto debería ser elegir cliente y tarea; no recorrer doce capítulos.

| Momento de trabajo | Estado actual | Efecto | Decisión aplicada |
| --- | --- | --- | --- |
| Empezar una pieza | El Canvas queda después de introducción y fundamento. | Aumenta el tiempo hasta la primera acción útil. | Añadir una Mesa de hoy inmediatamente después del hero, con cliente, objetivo y acceso al Canvas. |
| Priorizar la jornada | No existe una vista de borradores, resultados o reglas activas por cliente. | La persona debe reconstruir el contexto navegando por la página. | Mostrar señales de trabajo: borradores, piezas por analizar y reglas de marca. |
| Usar la biblioteca | La biblioteca es completa, pero aparece como bloque largo de consulta. | Puede invitar a navegar fórmulas antes de definir una promesa. | Recordar en la Mesa de hoy que la biblioteca llega después de definir cliente, objetivo y prueba. |
| Recuperar trabajo | Historial permite revisar y registrar resultados, pero no es el punto de entrada. | Se pierden continuidad y sensación de cola de trabajo. | Incluir acceso directo a historial desde el tablero diario. |
| Trabajar por cliente | El modelo admite clientes y reglas, pero la cartera inicial estaba vacía. | No había una ruta directa para cada cuenta. | Dar de alta Mimesa, Papelon, Dulfit y Gella con sector pendiente de definir. |

## Flujo diario recomendado

> **1. Elegir cliente → 2. Definir objetivo → 3. Escribir tensión y prueba → 4. Construir hook y rótulo → 5. Auditar → 6. Guardar ficha → 7. Registrar resultado.**

El manual sigue disponible como respaldo de criterio. La Mesa de hoy cambia la jerarquía: el trabajo empieza en una decisión concreta y la formación aparece solo cuando la persona necesita consultarla.

## Validación visual

La Mesa de producción se verificó a 1280 px y 375 px. En escritorio, cliente, objetivo, borradores, piezas sin resultados y regla activa quedan visibles sin desplazamiento previo. En móvil, la secuencia se conserva en una sola columna: cliente, objetivo, CTA de ficha y señales de trabajo; los controles mantienen tamaño legible y el menú permite volver al manual cuando hace falta.

## Validación autenticada

La integración protegida confirmó que **Mimesa, Papelon, Dulfit y Gella** se devuelven en la cartera del usuario autenticado, junto con el flujo de regla, ficha y resultado real. La prueba de navegador comprobó que la Mesa abre el Canvas desde su CTA y conserva acceso a auditor, historial, filtros y exportación.
